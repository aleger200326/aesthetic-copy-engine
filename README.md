# Aesthetic Copy Engine

Генератор текстов для товаров, бьюти и рекламы. Пять стартовых записей перенесены с фотографиями и оформлением из исходной ленты.

## Быстрый старт

1. Откройте сайт и нажмите «Подключить Gemini».
2. Перейдите в [Google AI Studio](https://aistudio.google.com/api-keys), войдите в Google и создайте личный API-ключ.
3. Вставьте ключ в настройках сайта и сохраните.
4. Выберите нишу, заполните детали и создайте три варианта текста.

Ключ хранится только в браузере пользователя и отправляется напрямую в Google при генерации. В исходниках и на сервере общего ключа нет. Лимиты и доступность модели зависят от проекта Google.

## Лента

Стартовая лента одинаковая на всех устройствах. Новые результаты, загруженные фотографии и правки хранятся в IndexedDB конкретного браузера. Автоматической синхронизации личных результатов между устройствами нет. Очистка данных браузера удаляет личные результаты и ключ.

## Запуск

Это статический сайт: HTML, CSS и JavaScript без сборки. Публикуйте корень репозитория на статическом хостинге с HTTPS.
